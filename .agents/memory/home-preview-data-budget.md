---
name: Home preview data budget
description: User intent behind varied, personalized home audio previews and limited speaking.
---

The home preview should feel interactive from the beginning instead of repeatedly presenting Trump and Biden. Show two personas, allow visitors to rotate or select them, and offer a name-addressed pitch about why to choose each voice.

**Why:** The user said the fixed pairing would become redundant and asked to limit speaking to about four personas to save data.

**How to apply:** Preserve variety and personalization when changing the entry experience, but keep the low-data speaking limit. Expanding the selectable roster is not permission to generate or download audio for the whole roster.

The user wants home samples to feature controversial, ideologically opposing figures pitted against one another. Do not use Malcolm X as a home sample; this exclusion is not a request to remove him from the rest of the app.

**Why:** The user explicitly requested stronger ideological opposition and excluded Malcolm X from samples.

**How to apply:** Preserve this editorial constraint when changing the sampler roster or its automatic matchups.
